04 / TECHNOLOGY STACK

Lightweight at the core.
Extensible where it matters.

The desktop shell is built with Python's standard GUI toolkit. The heavy lifting remains with your installed EDA toolchain; machine-learning dependencies are optional.

The app orchestrates external EDA tools; it does not bundle ORFS, OpenROAD, Yosys or KLayout.

06 / QUICK START

Get your workstation running.

Install the Python application, point it to your ORFS checkout, and select a design configuration.

01

Clone the project

Download the source and enter the repository directory.

02

Prepare Python

Use Python 3.10+ with Tkinter available. Create a virtual environment.

03

Configure ORFS

In Settings → Paths, select the OpenROAD Flow Scripts root containing flow/ and use-openroad.sh.

04

Select a design and run

Activate config.mk from the project tree, then run individual stages or the full pipeline.

TERMINAL / INSTALLATION
# Clone the repository
git clone https://github.com/Mihir-Mithani/OpenRoad_GUI.git
cd OpenRoad_GUI

# Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Optional: install AI + monitoring dependencies
pip install psutil lightgbm torch onnx onnxruntime scikit-learn pandas joblib

# Launch the desktop application
python3 main.py
07 / FAQ

Good to know before you begin.

Does this application include OpenROAD or Yosys?

No. It is a desktop interface and flow controller for an existing OpenROAD Flow Scripts installation. OpenROAD, Yosys, Make and related dependencies must be available through your ORFS environment.

Are AI features required?

No. The base interface and flow execution are designed around Python and Tkinter. AI prediction and resource-monitoring features require optional dependencies and suitable trained models.

Can I run just one flow stage?

Yes. The app documents per-stage execution as well as a full six-stage pipeline. Logs are streamed into the terminal/log panel.

How do I inspect the final GDS?

Use the GDS preview or open the generated file in KLayout. The application also provides OpenROAD GUI viewers for intermediate database checkpoints.

Which operating systems are supported?

The application uses Python and Tkinter, but the effective compatibility depends on your Python/Tk installation and the ORFS toolchain on the host operating system.
